Painel de avaliação espectral

Interface usada para inspecionar os candidatos do Pixel Purity Index

O que é

Cada classe usa 1.000 pontos sistemáticos fixos, consultados pelo WTSS em 184 compostos de 16 dias. O PPI é executado por classe × data sobre todos os pontos válidos da data, e o painel apresenta os até quatro candidatos retidos.

Os gráficos individuais mostram 128 curvas determinísticas de contexto e a média calculada sobre todos os pixels válidos. O avaliador seleciona nenhum, um, vários ou todos os candidatos com assinatura compatível com vegetação fotossinteticamente ativa, e a decisão é exportada em CSV.

Exemplo

Este repositório publica um painel, para que o procedimento possa ser examinado sem carregar os cinco arquivos completos:

Classe 02 — Vegetação Natural Florestal Secundária

184 datas, 735 candidatos. Os painéis das classes 01, 09, 10 e 11 seguem exatamente a mesma estrutura.

Como o painel foi gerado

Os painéis são construídos a partir dos candidatos e das séries publicados neste repositório, sem consulta remota:

  • pelo pacote: python -m worcap_endmembers build-panels
  • com o código à vista, célula a célula: notebooks/standalone/03_reconstruir_paineis.ipynb

Qualquer um dos dois regenera os cinco painéis em outputs/, diretório fora do controle de versão.

As avaliações resultantes

Os CSVs exportados dos cinco painéis estão em reviews/incoming/, e as decisões consolidadas em reviews/validated/. O critério aplicado está descrito em docs/materials/metodologia.md.
